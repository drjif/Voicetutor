    Step by step

    How to move a Quizlet set to Anki

    Quizlet can export a set as plain text. Anki can import plain text. This page fixes the formatting in between so the import works on the first try.

    1. Export the set from Quizlet.

      Open the set, select the three-dot menu and choose Export. Keep Tab between term and definition and New line between rows, then copy the text.

    2. Paste it into the converter.

      Paste the text into the box on this page, or open the exported .txt file. Check the preview of your first cards.

    3. Download the Anki file.

      Select Download for Anki to save a .txt file that already tells Anki which separator and settings to use.

    4. Import it in Anki.

      In Anki desktop choose File, then Import, select the file, confirm the Basic note type and your deck, and select Import. Sync to see the cards on your phone.

    What the converter keeps

    • Every term and definition in the export, in the same order
    • Definitions that span several lines, as line breaks in Anki
    • Accents, symbols and non-Latin scripts
    • Quotes, ampersands and angle brackets, escaped so Anki shows them correctly

    You can also flip the cards so the definition is on the front, name the Anki deck before you download, or save a CSV for Excel and Google Sheets.

    What it can’t move

    • Images, diagrams and audio, because Quizlet’s text export leaves them out
    • Your Quizlet progress, stars and study history
    • Sets you can’t export from Quizlet in the first place

    Anki schedules every imported card as new, so your reviews start fresh.

    Common questions

    Quizlet to Anki FAQ

    Is this Quizlet to Anki converter free?

    Yes. It is free, needs no account or sign-up, and the tool sets no limit on how many cards you convert.

    Are my flashcards uploaded to a server?

    No. The conversion runs in your browser with JavaScript. The text you paste or open is not sent to a same3le server.

    How do I export a set from Quizlet?

    Open the set in Quizlet, select the three-dot menu and choose Export. Keep Tab between term and definition and New line between rows, then copy the text or download the file.

    Does it keep images and audio from Quizlet?

    No. Quizlet's text export contains only terms and definitions, so images and audio are not included. You can add them to the cards in Anki after importing.

    What if my terms or definitions contain commas?

    Export from Quizlet with Tab between term and definition. The converter splits each line at the first tab, so commas inside your cards stay where they are.

    Which versions of Anki can import the file?

    Anki 2.1.54 and later read the settings at the top of the file automatically. In older versions, choose Tab as the field separator and turn on Allow HTML in fields when you import.

    Can I study the cards without installing Anki?

    Yes. same3le, the free app that made this converter, reads each question aloud and listens to your spoken answer in the browser. Use the button under your converted cards to start.
