Step 2

Choose link access or upload a CSV.

Direct Google Sheet loading requires the selected sheet tab to be readable through a link. For private or sensitive study material, export a CSV and upload it locally instead.

Google Sheet link

  1. Open the sheet.
  2. Select Share.
  3. Under General access, select Anyone with the link and Viewer.
  4. Copy the address from the browser.
  5. Paste it into same3le and select Load sheet.
  6. Optional: sign in and choose Save to my account so the sheet reappears under My decks.

Anyone who has that link may be able to access the sheet. Do not use this method for confidential content. Saving to an account stores spreadsheet identifiers, not the question text.

CSV upload

  1. In Google Sheets, open File.
  2. Choose Download.
  3. Select Comma-separated values (.csv).
  4. Upload the file to same3le.

The current prototype reads the CSV in the browser rather than intentionally uploading the file to an application server.

Step 3

Pick a study mode and press start.

Answer out loud

The microphone listens after each question. This works best in supported versions of Chrome or Edge and when technical vocabulary has accepted alternatives.

Listen and review

No microphone. The app asks, waits for the thinking time you choose, and reads the stored answer.

Lock-screen review

An experimental continuous spoken track for the remaining rows. Phone and browser background-audio rules still apply.

Tips for large spreadsheets

  • Put one testable idea in each row.
  • Remove blank rows and merged cells.
  • Use short headers in the first row.
  • Keep the correct tab selected when copying the Google Sheets URL.
  • Start at a later row when resuming a long session.

Content you should not add

  • Patient names, dates of birth, medical record numbers, or other PHI
  • Confidential institutional data
  • Secure examination questions recalled from a test
  • Paid question-bank material you do not own or have permission to use
  • Information requiring a regulated secure storage environment

Troubleshooting

Google Sheets flashcard FAQ

Why can’t same3le read my sheet?

Check that the link is valid, the correct tab is selected, and General access is set to Anyone with the link — Viewer. A school or work Google account may block public link sharing; CSV upload is the alternative.

Does editing the sheet change the app?

Reload the sheet in same3le to pull the latest rows. The app does not continuously sync changes in the current prototype.

Is using Google Sheets free?

same3le’s current core spreadsheet-to-voice workflow is free. Google’s own account and service terms still apply to your Sheet.

Will Supabase store the spreadsheet?

The planned Supabase backend is intended for authentication, consent records, subscription status, and limited usage events—not automatic storage of question-bank content. Any future change would be disclosed before collection.
