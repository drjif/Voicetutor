Media Session handoff test

This test uses a normal HTTPS MP3 plus the browser Media Session API so iOS can expose it as system media.

1. Keep your iPhone connected to the Tesla by Bluetooth.

4. Let it play for at least 10 seconds.
5. Watch the Tesla screen for the same “audio is playing on your phone / switch?” prompt you got with YouTube.
